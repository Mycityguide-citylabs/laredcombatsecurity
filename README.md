# La'Red Combat Security Website

Next.js 16 + 21st.dev components

## Overview

Professional security services website for La'Red Combat Security (PVT) LTD — registered under Act (Chapter 24:31). Armed guards, static guards, CCTV, rapid response, K9 patrols, event security across Zimbabwe.

## Tech Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- shadcn/ui + Radix UI
- Framer Motion
- 21st.dev components

## 21st.dev Components Used

- Hero: Enterprise-Ready Hero Section (8156)
- Navigation: Header Navbar (18258)
- Services: Services (4192) + Services Card (7795)
- Security Features: Alqemist Security (14889), Shine Border Security Card (18018)
- Testimonials: Testimonial Basic (18913)
- Contact: Contact Form (35258)
- Footer: Footer with Suite (29773)

## Getting Started

```bash
npm install
npm run dev
```
